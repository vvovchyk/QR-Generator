# Генератор QR-кодів

Статичний вебзастосунок для створення QR-кодів із тексту, посилань, Wi-Fi, контактів, електронної пошти, телефону та SMS. Підтримує готові стилі, перевірку контрасту, копіювання та завантаження PNG/SVG із вільним полем для сканування.

## Локальний запуск

Відкрийте `index.html` у браузері. Для завантаження QRCode.js з cdnjs потрібне підключення до інтернету. Самі дані для QR-коду обробляються у браузері й не надсилаються на сервер.

## Деплой на GitHub Pages

Workflow `.github/workflows/deploy.yml` автоматично публікує сайт після push у гілку `main` або вручну через **Actions → Deploy to GitHub Pages → Run workflow**.

1. У репозиторії відкрийте **Settings → Pages**.
2. У полі **Build and deployment → Source** виберіть **GitHub Actions**.
3. Зачекайте на завершення workflow **Deploy to GitHub Pages** у вкладці **Actions**.
4. Відкрийте адресу сайту, зазначену у workflow run або в **Settings → Pages**.

Проєкт не потребує кроку збірки чи встановлення залежностей.
