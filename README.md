# Генератор QR-кодів

Статичний вебзастосунок для створення QR-кодів із тексту або посилання. Розмір і кольори можна налаштувати перед генерацією; результат завантажується у форматі PNG.

## Локальний запуск

Відкрийте `index.html` у браузері. Для генерації QR-кодів потрібне підключення до інтернету, оскільки бібліотека QRCode.js завантажується з cdnjs.

## Деплой на GitHub Pages

Workflow `.github/workflows/deploy.yml` автоматично публікує сайт після push у гілку `main` або вручну через **Actions → Deploy to GitHub Pages → Run workflow**.

1. У репозиторії відкрийте **Settings → Pages**.
2. У полі **Build and deployment → Source** виберіть **GitHub Actions**.
3. Зачекайте на завершення workflow **Deploy to GitHub Pages** у вкладці **Actions**.
4. Відкрийте адресу сайту, зазначену у workflow run або в **Settings → Pages**.

Проєкт не потребує кроку збірки чи встановлення залежностей.
